# DUET NIGHT ABYSS: DEMON WEDGE BUILDER DATA (FOR AI COPILOT)

This file provides a structured mapping of Demon Wedge stats and effects to the specific "Damage Buckets" in the Duet Night Abyss damage formula. This is the essential data required for building an accurate damage calculator or build optimizer.

## 1. DAMAGE BUCKET DEFINITIONS

All percentage-based stats are **ADDITIVE** within their assigned bucket and **MULTIPLICATIVE** between buckets.

| Bucket ID | Bucket Name | Formula Component | Stacking Type | Notes |
| :--- | :--- | :--- | :--- | :--- |
| SCALAR\_ATK | Base ATK Scalar | Character/Weapon Final ATK | Additive | Includes ATK%, Smash ATK%, Slash ATK%, Spike ATK%, Elemental ATK% |
| SCALAR\_HP | Base HP Scalar | Character Final HP | Additive | Includes HP% |
| SCALAR\_DEF | Base DEF Scalar | Character Final DEF | Additive | Includes DEF% |
| MV\_DMG | MV Multiplier | (1 + SUM(Skill DMG%)) | Additive | Applies to Skill DMG% stat |
| DMG\_BOOST | DMG Boost Multiplier | (1 + SUM(DMG Boost)) | Additive | Includes General DMG Boost, Weapon DMG, Skill DMG (from set effects) |
| CRIT\_DMG | CRIT Multiplier | (1 + CRIT Level * (SUM(Crit DMG) - 1)) | Additive | Applies to Crit DMG% stat |
| CRIT\_RATE | Crit Chance | Crit Chance % | Additive | Affects CRIT Multiplier activation chance and CRIT Level |
| UTILITY | Utility/Other | N/A | N/A | Stats that do not directly affect the damage formula (e.g., Tolerance, ATK Speed, Max Sanity) |

## 4. CALCULATOR LOGIC REQUIREMENTS

The AI Copilot must implement the following logic to correctly calculate the impact of a Demon Wedge:

1.  **Input:** Accept the Demon Wedge's stat value and the current total sum of that stat's bucket (e.g., New ATK% = 30%, Current Total ATK% = 150%).
2.  **Additive Summation:** Calculate the new total bucket value: $\text{New Total ATK}\% = 150\% + 30\% = 180\%$.
3.  **Marginal Gain Calculation:** The true damage increase is the ratio of the new multiplier to the old multiplier.
    $$\text{Damage Gain} = \frac{1 + \text{New Total Stat}\%}{1 + \text{Old Total Stat}\%} - 1$$
    *   *Example (ATK%):* $\text{Damage Gain} = \frac{1 + 1.80}{1 + 1.50} - 1 = 0.12 \text{ or } 12\%$
4.  **Demonstration of Multiplicative Stacking:** The calculator should show that a 30% ATK% (SCALAR\_ATK) provides a smaller gain than a 30% DMG Boost (DMG\_BOOST) if the other bucket is low, and vice-versa. This is the core purpose of the tool.

This structured data should allow the AI Copilot to accurately model the Demon Wedge system.
